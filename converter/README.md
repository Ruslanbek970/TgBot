# converter — модуль конвертации файлов (Разработчик 2)

Self-hosted конвертер. Ничего не отправляет в чужое облако — всё крутится на нашей стороне (важно для конфиденциальности документов).

## Публичный API

Одна функция — её вызывает бот:

```python
from converter import convert

out_path = convert(input_path, target_format)   # -> путь к готовому файлу
```

- `input_path` — путь к исходному файлу
- `target_format` — формат без точки: `"pdf"`, `"docx"`
- возвращает путь к результату во **временной** папке (вызывающий удаляет его после отправки — есть хелпер `converter.utils.cleanup`)
- при ошибке кидает наследника `ConverterError` (см. `exceptions.py`)

## Что поддерживается

| Из | В | Движок |
|----|----|--------|
| docx, doc, odt, rtf, txt, xlsx, xls, ods, csv, pptx, ppt, odp | **pdf** | LibreOffice |
| png, jpg, jpeg, bmp, tiff | **pdf** | img2pdf (fallback — LibreOffice) |
| pdf | **docx** | pdf2docx |

Добавить направление = дописать пару в `SUPPORTED` (`core.py`) и, если нужно, ветку маршрутизации.

## Зависимости

Python-библиотеки — в общем `requirements.txt` (`pdf2docx`, `img2pdf`).

**LibreOffice ставится системно**, не через pip:
- Windows: установщик с libreoffice.org
- Ubuntu/Debian: `sudo apt install libreoffice`
- macOS: `brew install --cask libreoffice`

Если `soffice` не в PATH — задать путь в переменной окружения `SOFFICE_PATH`.

## Что заложено (готчи, которые обычно ломают такие конвертеры)

- **Параллельные запросы** — у каждого вызова LibreOffice свой профиль + лок, не падает на "another instance is running".
- **Таймаут 120 c** — битый файл не вешает процесс навсегда.
- **Очистка temp** — временные файлы удаляются после отдачи (`utils.cleanup`).
- **Лимит входа 20 МБ** — совпадает с лимитом скачивания Telegram-бота.
- **Понятные ошибки** — бот показывает текст, а не трейсбек.

## Про внешние API (iLovePDF и т.п.)

Осознанно **не используем** для основного пути: такие сервисы гоняют файлы через свои серверы — это против «конфиденциальность на нашей стороне». Если очень надо как запасной вариант для экзотических форматов — добавляется отдельной функцией-движком в `engines.py`, но по умолчанию выключено.
