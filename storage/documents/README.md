# documents — демо-данные хранилища

Структура: одна папка = одна компания, внутри её документы.

```
documents/
  Тексол Транс/
    протокол.txt
    сертификат.txt
```

Бот по запросу «документы по Тексол Транс» отдаёт все файлы из соответствующей папки.

> ⚠️ Это **демо-данные** для проверки. Реальные конфиденциальные документы
> сюда в открытом виде класть и коммитить в git не нужно — этим займётся
> Разработчик 1 (нормальное хранилище с шифрованием/правами доступа).
