# TgBot — телеграм-бот для документов

Бот для работы с документами: **выдаёт нужные документы по запросу** и **конвертирует файлы** (Word↔PDF и др.). Всё self-hosted — файлы не уходят в чужое облако.

Главный сценарий:
> «нужны документы по ТОО «Тексол Транс»» → бот возвращает протокол, сертификаты и т.д.
> Плюс: пришли файл → получи его в нужном формате.

---

## Кто что делает

| Модуль | Ответственный | Статус |
|--------|--------------|--------|
| [`converter/`](converter/) — конвертация файлов | **Разработчик 2** | ✅ готов |
| [`storage/`](storage/) — хранилище и выдача документов | Разработчик 1 | 🟡 заглушка (файловая), дорабатывается |
| [`bot/`](bot/) — интерфейс бота и команды | Разработчик 3 | 🟡 минимальная рабочая версия, дорабатывается |

Модули общаются только через публичный API — можно пилить параллельно, не мешая друг другу:

```python
convert(input_path, target_format) -> output_path   # converter (Разработчик 2)
find_documents(query) -> list[str]                  # storage   (Разработчик 1)
```

> Заглушки Dev 1 и Dev 3 написаны, чтобы всё **запускалось и работало end-to-end** уже сейчас. Разработчики 1 и 3 забирают свои папки и дорабатывают, не трогая чужой код.

## Структура

```
TgBot/
├── bot/            # Разработчик 3: команды и хендлеры телеграм-бота
│   ├── config.py   #   токен из .env, лимиты
│   └── main.py     #   /start, приём файла -> конвертация, "документы по X"
├── converter/      # Разработчик 2: конвертер (ГОТОВО)
│   ├── core.py     #   convert() — единственная точка входа
│   ├── engines.py  #   LibreOffice, pdf2docx, img2pdf
│   ├── utils.py    #   расширения, размер, очистка temp
│   └── exceptions.py
├── storage/        # Разработчик 1: хранилище (заглушка)
│   ├── store.py    #   find_documents(), list_companies()
│   └── documents/  #   демо: папка = компания, внутри её доки
├── tests/          # базовые тесты конвертера
├── run.py          # точка входа: python run.py
├── requirements.txt
└── .env.example
```

## Запуск

```bash
# 1. зависимости Python
pip install -r requirements.txt

# 2. LibreOffice (движок Word/Excel/PPT -> PDF), СИСТЕМНО:
#    Windows — установщик с libreoffice.org
#    Ubuntu  — sudo apt install libreoffice
#    macOS   — brew install --cask libreoffice

# 3. токен бота
copy .env.example .env      # Windows  (Linux/macOS: cp .env.example .env)
#    -> впиши BOT_TOKEN от @BotFather

# 4. старт
python run.py
```

### Как пользоваться в Telegram
- **Конвертация:** пришли файл. В подписи укажи `pdf` или `docx` (по умолчанию: Word/Excel/картинка → PDF, PDF → Word).
- **Документы по компании:** напиши `документы по Тексол Транс`.

## Что дорабатывают дальше

- **Разработчик 1 (storage):** заменить файловую заглушку на нормальное хранилище (индекс/БД, шифрование, права доступа), сохранив сигнатуру `find_documents()`. Реальные документы в git не коммитить.
- **Разработчик 3 (bot):** расширить команды, инлайн-поиск, аккуратные ответы, при необходимости — очередь задач.
- **Разработчик 2 (converter):** по запросу добавить направления (напр. PDF→картинки), объединение PDF и т.п. — дописываются в `SUPPORTED` + `engines.py`.

## Почему без внешних API (iLovePDF и пр.)
Такие сервисы отправляют файлы на свои серверы — это против требования «конфиденциальность на нашей стороне». Поэтому конвертация локальная (LibreOffice + библиотеки). Внешний API можно подключить запасным движком в `converter/engines.py`, но по умолчанию он выключен.
