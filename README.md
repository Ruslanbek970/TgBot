# TgBot — AI-телеграм-бот для работы с документами

Умный бот для управления документами компаний и конвертации файлов. Бот поддерживает гибридный режим: может реагировать на строгие Slash-команды, а также общаться на естественном языке, самостоятельно выбирая нужный инструмент через AI-маршрутизатор (Gemini).

Главные сценарии:
> **Конвертация:** Пришлите файл Word/PDF/Изображение — бот вернет его в нужном формате.
> **Умный поиск (ИИ):** Напишите «какие файлы есть по тексолу?», и ИИ сам вызовет нужный инструмент, исправит опечатки (тексо**н** → тексо**л**) и выдаст вам документы.
> **AI Метаданные:** Отправьте документ с подписью `в <компания>`, и ИИ сгенерирует для него краткое резюме (meta.txt), а затем сохранит вместе с оригиналом.

## Доступные инструменты (CRUD)

Ботом можно управлять классическими командами:
- `/create_company <имя>` — Создать компанию
- `/delete_company <имя>` — Удалить компанию со всеми файлами
- `/list_companies` — Список всех компаний
- `/list_files <компания>` — Список файлов компании
- `/delete_file <компания> <имя_файла>` — Удалить конкретный файл

Или **напрямую обычным текстом**: «создай компанию Магнум», «удали файл отчет.pdf у Магнума», «какие у нас есть компании?».

## Запуск

### Вариант A — Docker (рекомендуется)
Образ уже содержит LibreOffice (для конвертации) и все необходимые Python-зависимости.

```bash
cp .env.example .env
# Обязательно впишите BOT_TOKEN (от @BotFather) и GEMINI_API_KEY (Google AI Studio) в .env
docker compose up --build -d
```

### Вариант B — Локально (без Docker)

```bash
pip install -r requirements.txt
cp .env.example .env # Впишите BOT_TOKEN и GEMINI_API_KEY

# Внимание: Для конвертации Word->PDF потребуется системно установленный LibreOffice
python run.py
```

## Конфиденциальность и данные
- **Конвертация:** Выполняется строго **локально** (через LibreOffice/pdf2docx). Мы не отправляем ваши документы на сторонние сервисы вроде iLovePDF.
- **Работа с ИИ:** Свободный пользовательский текст отправляется в Google Gemini для понимания намерений (роутинга). **Сами файлы в ИИ не отправляются**, за одним исключением: при загрузке нового документа в компанию (когда в подписи указано `в <название_компании>`) документ временно передается в Gemini File API исключительно для создания 1-2 предложений описания (метаданных). Описание сохраняется рядом с оригиналом в файле `.meta.txt`.
